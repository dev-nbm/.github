# .github

Shared defaults for every `dev-nbm` repo that doesn't define its own.

- `.github/ISSUE_TEMPLATE/feature.yml` and `bug.yml`: issue forms. New issues are added to the [EARO board](https://github.com/users/dev-nbm/projects/4) automatically.

New features and bugs are filed in the hub repo, [dev-nbm/earo](https://github.com/dev-nbm/earo). Code repos get sub-issues once work is triaged.
